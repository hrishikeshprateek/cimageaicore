# Bundled fonts (SIL Open Font License 1.1)

| File | Use | Licence |
|---|---|---|
| Poppins-Regular.ttf, Poppins-SemiBold.ttf | primary caption / lower-third font - covers Latin **and** Devanagari | OFL-Poppins.txt |
| NotoSansDevanagari-Regular.ttf, NotoSansDevanagari-Bold.ttf | Devanagari fallback for runs the primary font cannot draw (e.g. a Latin-only brand font) | OFL-NotoSansDevanagari.txt |

Override with `COMPOSER_FONT_REGULAR` / `COMPOSER_FONT_BOLD` (brand font) or per template (`font_regular` / `font_bold` in template.json).
